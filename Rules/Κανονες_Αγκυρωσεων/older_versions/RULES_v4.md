## 3. ΤΕΧΝΙΚΟΙ ΚΑΝΟΝΕΣ BERLIN WALL & ΑΓΚΥΡΩΣΕΩΝ

### 3.1 ΕΛΑΧΙΣΤΗ ΔΙΑΜΕΤΡΟΣ ΔΙΑΤΡΗΣΗΣ ΝΕΦΚΩΝ (MIN Ø800 mm)
* Εάν η στατική μελέτη ζητά διάμετρο διάτρησης πασσάλων **μικρότερη από 800 mm** (π.χ. Ø600 mm):  
  👉 **ΕΜΕΙΣ ΒΑΖΟΥΜΕ ΠΑΝΤΑ 800 mm ($\mathbf{\varnothing 800\text{ mm}}$ / $0.80\text{ m}$)!**
* Εάν η μελέτη ζητά διάμετρο $\ge 800\text{ mm}$ (π.χ. Ø800, Ø900, Ø1000 mm), εφαρμόζεται η διάμετρος της μελέτης.
* Ο όγκος εκσκαφής οπής και ο όγκος κουγκριού πάκτωσης υπολογίζονται υποχρεωτικά με βάση τη διάμετρο εφαρμογής (δηλαδή κατ' ελάχιστο $0.80\text{ m}$).

### 3.2 ΥΠΟΛΟΓΙΣΜΟΣ ΛΑΜΩΝ ΣΥΝΔΕΣΗΣ / ΕΝΙΣΧΥΣΗΣ ($L_{\text{beam}} / s_{\text{plate}}$)
* **ΑΠΑΓΟΡΕΥΕΤΑΙ** ο πολλαπλασιασμός με πλήθος λαμών ανά επίπεδο.
* Το πλήθος λαμών ανά πάσσαλο υπολογίζεται **αυστηρά** ως:  
  $$\text{Πλήθος Λαμών ανά Πάσσαλο} = \frac{L_{\text{beam}}}{s_{\text{plate}}} = \frac{\text{Συνολικό Ύψος Νέφκας}}{\text{Απόσταση που ζητά ο μελετητής}}$$
* Συνολικές λάμες έργου: $N_{\text{plates, total}} = N_{\text{holes}} \times \left(\frac{L_{\text{beam}}}{s_{\text{plate}}}\right)$.
* Συνολικό βάρος λαμών: $W_{\text{plates}} = N_{\text{plates, total}} \times \text{Βάρος 1 λάμας (kg)}$.

### 3.3 ΚΑΝΟΝΑΣ ΑΝΤΙΦΑΣΕΩΝ ΣΚΥΡΟΔΕΜΑΤΟΣ ΣΤΗ ΜΕΛΕΤΗ
* Εάν στα κατασκευαστικά σχέδια αναφέρονται δύο διαφορετικές κατηγορίες σκυροδέματος για το ίδιο στοιχείο:  
  👉 **Επιλέγουμε ΠΑΝΤΑ το ανώτερο στατικά σκυρόδεμα (π.χ. C35/45 έναντι C30/37).**  
  👉 **Προσθέτουμε ρητή τεχνική σημείωση** στο Φύλλο 1 και Φύλλο 2 ότι στη μελέτη δόθηκαν δύο κατηγορίες και επιλέχθηκε η ασφαλέστερη.

### 3.4 ΥΠΟΛΟΓΙΣΜΟΣ ΠΕΡΙΜΕΤΡΟΥ & ΠΑΣΣΑΛΩΝ ΜΕΣΩ ΔΙΑΣΤΗΜΑΤΩΝ (INTERVALS MATHEMATICS)
* Όταν σε μία πλευρά της εκσκαφής **δεν αναγράφονται ρητά αριθμητικά μέτρα**, το μήκος της πλευράς και ο αριθμός των πασσάλων **ΔΕΝ εκτιμώνται αυθαίρετα**.
* Μετράται ο ακριβής αριθμός των διαστημάτων (intervals) μεταξύ των διαδοχικών πασσάλων κέντρο-προς-κέντρο ($s_{\text{c/c}}$):  
  $$\text{Μήκος Πλευράς } L_i = (\text{Πλήθος Διαστημάτων}_i) \times s_{\text{c/c}}$$
* Συνολική Περίμετρος Έργου: $L_{\text{total}} = \sum L_i = \sum (\text{Διαστήματα}_i \times s_{\text{c/c}})$.
* Συνολικός Αριθμός Πασσάλων / Οπών: $N_{\text{holes}} = \sum \text{Διαστήματα} = \frac{L_{\text{total}}}{s_{\text{c/c}}}$.

## 6. ΜΕΘΟΔΟΛΟΓΙΑ ΜΕΤΡΗΣΗΣ ΣΤΟΙΧΕΙΩΝ ΑΠΟ ΣΧΕΔΙΑ CAD (OBJECT COUNTING METHODOLOGY)

# CAD / Engineering Plan Object Counting Methodology

When asked to detect and count structural elements in a drawing (piles, tie rods/holes, columns, openings) when NOT explicitly given in a BOQ, drawing text, or study:

1. **NEVER count manually by looking at the image (risk of hallucination). Always write and execute a Python OpenCV script.**
2. **PIPELINE PROTOCOL:**
   - **a. CONTEXT EXTRACTION (ROI):** 
     - Locate the hosting geometry first (e.g. wall contour, perimeter beam, grid axis).
     - Mask out irrelevant regions (text annotations, dimension arrows, hatching patterns) using color thresholding or bounding contours.
   - **b. ELEMENT TEMPLATE SELECTION:**
     - If circular (piles, core drills, holes): Use a synthetic dark disc kernel (`cv2.circle`) or `cv2.HoughCircles` with tuned radius and minimal blur (`ksize=3`).
     - If rectangular (columns, footings): Use `cv2.findContours` on thresholded lines, filtering by aspect ratio and area, OR a rectangular synthetic template.
     - If complex CAD block: Crop one clear sample from the image and apply `cv2.matchTemplate` with rotation invariance (or multi-angle if not symmetrical).
   - **c. NON-MAXIMUM SUPPRESSION (NMS):**
     - Always pass bboxes as `[x, y, w, h]` to `cv2.dnn.NMSBoxes`.
     - Set `score_threshold` and `nms_threshold` based on the spacing between elements.
   - **d. GEOMETRIC & PHYSICAL SANITY CHECKS:**
     - Filter candidates by verifying that the core/center pixel intensity matches the object type.
     - Verify that consecutive distances between detected objects conform to standard engineering spacings (e.g. c/c distance).
   - **e. OUTPUT:**
     - Draw red circles/boxes with consecutive numeric labels (1, 2, 3...) following the natural physical path (chainage).
     - Report the exact deterministic count and save the annotated image.
